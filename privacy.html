Privacy Policy

Last updated: May 2026

We collect nothing. No data. No tracking. No analytics.

What this extension does

Claude Project Pal is a Chrome extension that allows users to upload multiple files to Claude.ai project knowledge in bulk, instead of one file at a time.

Data we collect

None. This extension does not collect, store, transmit, or share any personal data, usage data, or analytics of any kind.

How the extension works

Your files stay local. Zip files you drop onto the extension are processed entirely within your browser. File contents are never sent to any server other than Claude.ai.

Claude.ai receives your files. The extension uploads files directly to Claude.ai using your existing logged-in session — identical to what happens when you upload manually. The extension does not intercept or store the content of these uploads.

Cookies are used for authentication only. The extension reads your lastActiveOrg cookie from claude.ai to identify which organisation your project belongs to. This is only used to construct the correct API request and is never transmitted anywhere except claude.ai directly.

Version checks. The extension makes one outbound request on popup open to a public GitHub file to check whether a newer version is available. This request contains no user data and no identifying information.

Third parties

This extension does not use any third-party analytics, advertising, or tracking services.

The version check contacts GitHub (raw.githubusercontent.com). GitHub's privacy policy applies to that single request.

Changes to this policy

If this policy changes, the updated version will be posted at the same URL and the extension version number will be incremented.
